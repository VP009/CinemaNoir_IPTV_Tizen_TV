# Bibliotecas locais

`shaka-player.hls.js` é o build HLS sem interface do Shaka Player 4.16.43. Ele é usado apenas como alternativa no navegador para manifests `.m3u8`; os controles continuam sendo os controles próprios e leves do Cinema Noir. Em Samsung Tizen, AVPlay continua sendo a primeira opção.

Não há CDN, npm, React, TypeScript, Vite, Tailwind ou módulos ES em tempo de execução.
